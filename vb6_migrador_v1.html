4. Tabla Maestra de Ejecución

# Orden Tipo Nombre Rol / Responsabilidad Dependencias
00.0 Rule MIGRATION_RULES.md Establece la ley (Strict Types, WAL Mode, Signals). Ninguna (Es la base)
01.0 Workflow /orchestrate-migration Workflow Maestro. Orquesta Auditar -> DB -> UI. Req: Todo el Kit
01.1 Agent migration-orchestrator Project Manager. Ejecuta el workflow maestro. Req: task.md
02.0 Workflow /audit-legacy Escaneo inicial para dimensionar el esfuerzo. Req: Código Fuente
02.1 Agent vb6-analyst Lee el código fuente VB6. Req: Skills/Legacy-Decoding
02.2 Skill legacy-decoding Conocimiento sobre sintaxis VB6 y OCX. -
02.3 Script vb6_parser.py Extrae controles y coordenadas de .frm. Invocado por vb6-analyst
03.0 Workflow /migrate-db Mueve los datos primero (Data First Strategy). Req: .mdb file
03.1 Agent data-migrator Genera Prisma Schema y Seed Scripts. Req: Skills/Db-Transform
03.2 Skill db-transform Mapping de tipos Access -> SQLite. -
03.3 Script schema_converter.py Convierte tipos de datos automáticamente. Invocado por data-migrator
04.0 Workflow /migrate-ui Se ejecuta N veces (una por formulario). Req: DB Migrada
04.1 Agent angular-architect Crea Componentes, HTML y CSS. Req: Skills/Modern-Stack
04.1 Agent backend-engineer Crea Endpoints API REST para ese Form. Paralelo a Angular
04.2 Skill modern-stack Patrones Angular (Signals) y Node (Layered). -
04.3 Script component_scaffolder.py Crea carpetas y ficheros vacíos. Invocado por angular-architect
05.0 Skill quality-gates Valida que el código cumpla los estándares. Usado al final de cada paso
